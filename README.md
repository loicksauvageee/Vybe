# Vybe — Infra Cloud Azure de A à Z

Construction, chapitre par chapitre, de l'infrastructure cloud complète d'une néobanque fictive : Azure, Terraform, GitHub Actions, orchestration de conteneurs, observabilité, sécurité continue.

Chaque chapitre est documenté comme une vraie décision d'architecture d'entreprise : contexte, décision, alternatives considérées, conséquences.

## Le projet : Vybe

Néobanque B2C fictive, opérant en Europe (hors France), avec un positionnement différenciant : un compte bancaire classique couplé à un accès privilégié à des événements (concerts, festivals) — upgrade automatique, goodies, avantages selon usage.

Cadre réglementaire pris en compte : PSD2, licence e-money (EMD2), AML/KYC, RGPD, DORA, PCI-DSS.
